# Quick Deploy Guide (Phone Only)

## What you need
- Phone browser
- GitHub account: https://github.com  (free)
- Expo account:  https://expo.dev     (free)

---

## 1. Upload to GitHub

1. github.com → Sign in → tap + → New repository
2. Name: scanmasterpro → Public → Create repository
3. Press the . (dot) key OR go to: github.dev/YOUR_USERNAME/scanmasterpro
4. This opens a browser code editor
5. Drag & drop ALL files from inside the unzipped ScanMasterPro folder into it
6. Ctrl+Shift+G (or Source Control icon) → type "first commit" → click Commit

---

## 2. Connect Expo to GitHub

1. expo.dev → Sign in → tap your avatar → Settings → Connections
2. Connect GitHub account
3. Go back to Dashboard → New Project → Import from GitHub
4. Select: scanmasterpro → Create Project

---

## 3. Build APK

1. Inside your Expo project → tap Builds (left menu)
2. New Build → Android → Profile: preview → Build
3. Wait ~15 min
4. Download the .apk when ready

---

## 4. Install on Android

1. Download APK to your phone
2. Open Files app → tap the APK
3. Allow "Install unknown apps" if asked
4. Install → Open ScanMaster Pro ✓
